Support

If something feels off, start here. A short description and the conversion log usually make it easy to figure out what happened.

Privacy Terms Support

Contact

Email alice.turcanu91@gmail.com with your app version, macOS version, and the file type you tried to convert.

Helpful Details to Include

  • What file type you converted.
  • Whether the app showed an error or produced unexpected Markdown.
  • Whether you used the cleanup options in Settings.
  • Any steps that reliably reproduce the problem.

Common Checks

  • Confirm the source file opens in another app.
  • Try converting a different file to see whether the issue is specific to one document.
  • Make sure you granted access to the file if macOS asked for permission.
  • Check whether the Markdown output was copied or saved somewhere unexpected.

Conversion Logs

If conversion fails, FileMark may save a local diagnostic log on your Mac. That log can help explain why the conversion stopped and what the converter reported.

Feature Requests

Suggestions are welcome. The most useful requests usually describe the file type, workflow, or pain point they would improve.

Response Expectations

We try to reply as quickly as possible, but response time depends on the volume of messages and the complexity of the issue.
